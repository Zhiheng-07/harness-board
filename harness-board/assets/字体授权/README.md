# 字体授权

看板页面 `board.html` 里嵌了三套字体的子集（只留页面用到的字，内嵌为 woff2），都按 SIL Open Font License 1.1 授权。授权全文就在本目录，子集保留了原字体的版权信息。

| 页面里的字体名 | 原字体 | 授权全文 |
|-|-|-|
| BoardDisp（标题、节点名）、BoardModel（模型名） | Montserrat 600、800 | `OFL-montserrat.txt` |
| BoardMono（其余文字、符号） | JetBrains Mono 400、500 | `OFL-jbm.txt` |
| BoardSC（中文）、BoardModelSC（模型卡的中文） | 思源黑体 Noto Sans SC 400、500、700 | `OFL-noto.txt` |

思源黑体的保留字体名是「Source」，子集没有用这个名字。

这些字体不属于 harness-board 的 MIT 授权范围，仍按 SIL OFL 1.1。

## Font licenses (English)

`board.html` embeds subsets of three font families (only the glyphs the page uses, inlined as woff2). All of them are licensed under the SIL Open Font License 1.1; the full license texts are in this folder, and the subsets keep the original copyright notices.

| Font name in the page | Original font | License text |
|-|-|-|
| BoardDisp (titles, node names), BoardModel (model name) | Montserrat 600, 800 | `OFL-montserrat.txt` |
| BoardMono (other text, symbols) | JetBrains Mono 400, 500 | `OFL-jbm.txt` |
| BoardSC (Chinese), BoardModelSC (Chinese on the model card) | Noto Sans SC (Source Han Sans) 400, 500, 700 | `OFL-noto.txt` |

The Reserved Font Name of Source Han Sans is "Source"; the subsets do not use that name.

These fonts are not covered by harness-board's MIT license; they remain under the SIL OFL 1.1.
